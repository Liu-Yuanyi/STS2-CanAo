# 一、核心机制

## 1. <mark style="background: #ABF7F7A6;">星</mark>与<mark style="background: #FFB86CA6;">月</mark>

**<mark style="background: #ABF7F7A6;">星</mark>** 与 **<mark style="background: #FFB86CA6;">月</mark>** 是本回合临时资源，回合结束时清空。

当你同时拥有至少 1 <mark style="background: #ABF7F7A6;">星</mark>和 1 <mark style="background: #FFB86CA6;">月</mark>时，不断地消耗 1 <mark style="background: #ABF7F7A6;">星</mark>和 1 <mark style="background: #FFB86CA6;">月</mark>，直至<mark style="background: #ABF7F7A6;">星</mark>或<mark style="background: #FFB86CA6;">月</mark>为0，然后将等量张【星月合击】加入手牌。

| 卡牌   | 类型   |  费用 | 效果                           |
| ---- | ---- | --: | ---------------------------- |
| 星月合击 | 衍生攻击 |   0 | 虚无。造成 5/7 点伤害。获得 4/6 点格挡。消耗。 |
## 2. <mark style="background: #A0B0FFA6;">凤威</mark>

每有 1 点<mark style="background: #A0B0FFA6;">凤威</mark>，你的【星月合击】伤害和格挡各提高 1。

<mark style="background: #A0B0FFA6;">凤威</mark>可以为负数，此时【星月合击】伤害和格挡降低，但至少为0。

## 3. <mark style="background: #FF5582A6;">浴火</mark>

<mark style="background: #FF5582A6;">浴火</mark>：**这张牌被消耗前，会被免费打出。**

类似”奇巧“

规则细化：

- <mark style="background: #FF5582A6;">浴火</mark>本身不等于消耗，也不默认带有消耗。

| 情况               | 结果                |
| ---------------- | ----------------- |
| <mark style="background: #FF5582A6;">浴火</mark>牌不带“消耗”，被正常打出  | 触发一次效果（<mark style="background: #FF5582A6;">浴火</mark>不触发）     |
| <mark style="background: #FF5582A6;">浴火</mark>牌不带“消耗”，被其他牌消耗 | 触发一次效果（<mark style="background: #FF5582A6;">浴火</mark>）        |
| <mark style="background: #FF5582A6;">浴火</mark>牌带“消耗”，被正常打出   | 打出时触发一次，消耗前再触发一次  |
| <mark style="background: #FF5582A6;">浴火</mark>牌带“消耗”，被其他牌消耗  | 只触发一次效果（毕竟牌不能烧两次） |
