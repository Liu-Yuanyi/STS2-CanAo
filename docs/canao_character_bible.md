# 残傲人物圣经

> 本文档是残傲一切文案、对白与视觉的最高依据。与《新大事年表》冲突时以年表为准；
> 年表未载处，以本文为准；本文标【新增】的条目为本次重写补充。
> 配套文档：`canao_timeline.md`（事实层）、`canao_visual_bible.md`（视觉层）。

## 一、总览

- **姓名**：残傲
- **性别**：男
- **尊号**：天凤帝国十二族**青鸾七天凤**（"青鸾天凤"）
- **生年**：第 26 年（以云霜出生为第 0 年）
- **身份弧线**：梦留山的孤儿 → 帝国的长兄与老师 → 西都亿渠的天凤（479～502 在位）→
  陨山的归隐者 → 女儿王座后的最后一道影子
- **一句话定位**：一个把"守护"活成"占有"、把"失去"炼成"火焰"的帝王；
  他不是暴君，是一个用尽全力仍然弄丢过所有人的父亲。

## 二、人物小传

### 1. 云霜羽翼下（26～117）

残傲出生次年即随长姐云霜迁居梦留山。凤殿的冠冕、仪仗、嗣位课，
他一样都没有；他有的是一个二十六岁的姐姐，和一座山。

云霜教他读书、练剑、看星。他至今不用"母亲"这个词称呼任何养育者——
他的养育者有名字，叫云霜。

69 年，四十三岁的残傲与云霜共创**星月合击术**：星为引，月为应，双魂同调，
一击共发。这不是一套武技，是两个人把彼此的存在写进了对方的灵力回路。
此后两人结为夫妻——凤族对近亲结合的接受度远高于人类世界，无人置喙。
辉雪、辉月、辉雨相继出生。梦留山的灯火在那些年是真的暖的。

117 年，**湮门顿开**。没有征兆，没有敌人可杀，没有尸体可葬。
云霜与辉月被门吞没，辉雨当场死亡。残傲九十一岁，人生第一次
使出全力的星月合击——一个人打的。

### 2. 失怙与放逐（117～149）

此后三十二年，残傲不居凤殿、不问朝政、不见任何来吊唁的人。
他把梦留山封了，独自住在湮门出现过的崖侧。【新增：居崖侧】
他不是在接受失去，是在等门再开一次——等一次可以把自己也扔进去的机会。

149 年，辉雪叛离，投奔瓦魔族，拜在希溯门下。

消息传到梦留山时，残傲在崖侧坐了一整夜。天亮时他下山了——
他终于明白门不会为守候而开，但战争会为复仇而开。
他回居凤殿——不是为了王位，是为了把女儿从希溯手里拿回来。
这是他人生中第一次主动走进权力，动机从来不是权力。

### 3. 梦留山的长兄（149～451）

回殿的残傲成了帝国最特殊的宗室：不立储、不结党、不应酬，
只做两件事——对瓦魔族的备战，和教养幼小的弟妹。

187 年，八岁的倩雪被送上梦留山，一如当年一岁的他。206 年，他创出**青鸾勾法**——
没有云霜应和的星月，他独自探向夜空，勾来的星光冷而孤。"青鸾"由此成为他的名号。
253 年，他与倩雪共创**流萤剑法**，剑光如萤，散而不灭——那是他最后一次
与人共享创造的快乐。336 年，他在一次试手中**误残依絮**。

误残依絮是残傲心理结构里最危险的一道裂缝：他用星月合击的思路去教一个
没有与他同调过的人。错不在剑，在于他下意识地把妹妹当成了云霜。【推断】
依絮没有怪他——这才是最折磨他的地方。此后依絮长居北都无涯，
不再随军一线；489 年无涯失陷，她战死在无涯。

411 年寒羽出生，次年被送上梦留山。这个最小的妹妹是他亲手带大的，
**武功也大多为他所授**——他没有因为依絮的事收起剑，只是教得比从前更慢、
更耐心。弟妹之中，他与倩雪、寒羽最亲。

451 年，第一次御蛮会战，凤族败，**母亲聆知阵亡**。残傲率众撤回凤殿。
他在败军之中走在最后，没有回头。弟妹们以为长兄无泪；
只有倩雪看见他握剑的左手在抖——不是怕，是在克制回身杀进敌阵的自己。【新增】

### 4. 王冠之重（479～502）

479 年，凤溯失陷，**父亲莫亡为掩护八兄妹撤退，独面希溯，战死**。
残傲继位于西都亿渠。

那顶冠冕上全是父亲的血温。他登基的第一道诏令不是复仇，是收缩防线、
整军、核籍、立法度——他知道希溯在等一个疯了的继承人，他偏不给。【推断】
480 年，**世昌在南都边洲自立为王**。残傲没有发兵平叛，只回了一道诏书，
全文一句话："边洲的城墙上，站的还是凤族的人。"【新增：诏书内容】
他容得下弟弟的野心，因为弟弟的刀还朝着瓦魔族。

489 年，北都无涯失陷，依絮战死；同年，**倩雪于凤溯击败辉雪**，重夺凤溯，
分裂的帝国重新统一。捷报与讣告同日抵达。史官问他先记哪一笔，他说：
"都记。帝国不缺纸。"【新增】

### 5. 尘土之战（502）——详见时间线第三节

此战他做了四件事：生擒自己的女儿并囚于天笼；目睹湮门复开、妻子归来；
在云霜濒死之际以魂合之术将两人灵魂相连，从此同命；与云霜联手斩杀希溯。
代价是四弟尽首、挚友似光阵亡，他自己**灵力消耗大半**。

战后他做的第一件事是去天笼。囚期之内他没有劝降，只把聆知、莫亡、尽首、
似光的名字一个个讲给辉雪听。【新增】帝国的账簿上每一笔都是亲人——
女儿听懂了，他就赢了这场持续三百五十五年的父女之争。

### 6. 传位与归隐（502～557）

**残傲退位，传位于辉雪。** 因果链见时间线第四节：情感上，女儿是"失去过还站得
起来"的人；政治上，她是唯一能同时按住帝国主战派与瓦魔降系两边刀柄的人；
而他自己的灵力已不足以镇压四境。天凤退位诏书是他亲手写的，朱笔无一字颤抖。

世昌争位，败，**新君辉雪以叛国罪下令处死**。残傲已经退位，只是默许，
没有出言干预。他可以赦免一个失败者，但"兵变即继承通道"的先例不能开——
这个道理是他没有开口的全部理由，也是他一生不愿辩解的一件事。
他知道自己欠二弟一次像样的对话，永远欠着了。

此后他归隐**陨山**。521～526 年帝国分裂、525 年倩雪逼宫夺位，他都没有出手——
退位就是退位，天凤的信用比天凤的江山更重。【推断】
543 年，第二次御蛮会战，**寒羽战死于刑征之手**。他教出来的剑折在了御蛮，
而他在陨山，连她的最后一面都没有见到。【推断】

### 7. 最后一剑与地球（557～569）

557 年亿渠会战，辉雪即将被斩于刑征刀下。**残傲（和云霜）出手，击杀刑征**——
五十一年的杀母之仇，一剑了结。同役，六弟尘星战殁。他的灵力几乎被彻底摧毁。
此后他复隐居——这一次，在**地球**。

他一世都在失去，唯有这一次，是他自己走开的。【推断】

## 三、心理结构：同一颗核

残傲的傲慢、控制欲、责任感与悲痛**不是四种性格，是一种结构的四个面**：

> **核心信念：凡我所珍视者，皆会因我的松懈而失去。**
> 91 岁那年他只是没来得及出手，就失去了妻子和两个女儿——
> 这是全部心理的震源。

- **傲慢** = 震源的铠甲。他必须相信"我能护住"，否则就要直面"我护不住"。
  所以他的傲慢不是蔑视他人，是**禁止自己示弱**。他从不说"尽力"，只说"必胜"——
  因为上次他没说必胜的那次，输了云霜。
- **控制欲** = 恐惧的管理学。教养弟妹、核籍立法、亲自批诏、把女儿囚在看得见的天笼
  而不是杀在看不见的地方——他把一切都纳入自己的秩序，因为秩序是他唯一验证过
  有效的防护。云霜失踪后，他再不让任何珍视之物离开自己的感知范围。
  （讽刺的是，这恰恰是辉雪当年感到窒息而离开的原因之一。【推断】）
- **责任感** = 父亲之死的遗言。莫亡用命换他活下来继位，责任于是成了债务：
  他治理帝国不是享受权力，是在向一个死人分期付款。这解释了他的勤政、
  他的克制、以及他对"先例"近乎冷酷的坚持——包括默许世昌之死。
- **悲痛** = 唯一不许出口的货币。他从不哭、从不诉苦、从不提云霜的名字——
  悲痛一旦说出口就是消费它，他只允许自己**燃烧**它（浴火机制的心理学依据）。
  502 年魂合之后，云霜回到他神魂之内，悲痛才有了唯一的听众。

**行为的统一解释**：他做的每件"冷酷"的事（默许世昌伏法、囚亲女、不救分裂中的
帝国）都是责任感压过悲痛的结果；每件"温柔"的事（教养弟妹、容世昌七年、
亿渠会战最后一剑）都是悲痛绕过控制欲的瞬间。他不是一个矛盾的帝王，
他是一个**优先级永远明确**的父亲：秩序在前，私情在后——而私情从未缺席。

**魂合之后的他**：云霜常驻其神魂，可对话、可共感【新增，已获认可】。这使晚年的
残傲比在位时柔软——他终于可以"示弱"了，因为示弱的对象不会失去。对白中这表现为：
帝王腔不变，但偶有一句说给"她"听的话漏出来，随即收住。

## 五、语言与对白规范

### 5.1 自称与人称

| 场合 | 自称 | 说明 |
|---|---|---|
| 在位帝王/战斗威压/诏令语境 | **朕** | 唯一正式的帝王自称；从不滥用，一旦用出即不可置疑 |
| 私下、退位后、对云霜与至亲 | **我** | 魂合后使用频率上升 |
| 对云霜 | 直呼"云霜"，情急时"霜" | 从不称"皇后"——她不是他的附属，是他的同修 |
| 对辉雪 | "辉雪"；正式场合"天凰凤" | 传位后不再称"吾儿"，以示还政之实【新增】 |
| 对他人 | 直呼其名 | 不用尊称，也不许别人用谄称 |

英文对照：
- "朕"统一译作 **"We"**（royal we，首字母大写）或按语气译 "I"，威压句用 "We"。
- 说话对象第二人称用 "you"；不加 "my lord/sire" 类敬称。

### 5.2 语气规则

1. **短句。断言。不解释。** 他的句子以句号结尾，不以问号或感叹号结尾。
   疑问句只在一种情况下出现：质问敌人是否已尽全力。
2. **数字与名单入话。** 他习惯用名单、账簿、年份说话（"聆知，莫亡，尽首，似光。
   四个名字，四笔账。"），这是"账簿人格"的外化。
3. **不说的话**（禁忌清单）：
   - 不说"命运/天意"——他的一生是反天意的；
   - 不说"对不起"——除了依絮面前一次（而依絮死后他再不说）；【新增】
   - 不主动提"云霜"之名；提到时不加任何称谓修饰；
   - 不用"牺牲"一词谈别人——他只用于自己（"牺牲是帝王的税"【新增】）；
   - 不喊招、不解释招式、不在战斗中做战术解说。
4. **情绪温度曲线**：越痛越冷。最愤怒时语速最慢、用词最短。
   胜利时不庆祝，只核对（"清点伤员"）；失败时不辩解，只认账。
5. **幽默**：几乎没有；唯一的例外是归隐后偶尔被云霜逼出来的干巴巴冷笑话。
   Mod 战斗语境中不使用幽默。

### 5.3 游戏内对白样本（供本地化统一口径）

> 战斗/胜利/失败类对白应控制在 1～2 句、25 字以内（英文 12 词以内）。

- **角色选择界面描述**（见本地化）："青鸾七天凤。浴火为道，以失去为薪。"
- **进入战斗**："列阵。帝国没有第二场败仗。"
- **浴火触发**："烧掉的不是朕的羽毛，是朕的过去。"
- **星月合击**："星引，月应。"（最低限度地纪念，从不说全）
- **受重创**："……记下了。"（越痛越冷）
- **低血量**："朕还站着。这就是帝国还站着。"
- **胜利**："清点伤员。记下名字。"
- **失败/死亡**："云霜……账，还没还完。"（唯一一次允许名字出口）
- **对魔族敌人**："瓦魔族的刀，朕认得。朕的账，你们也该认得了。"
- **先古对话**（维持现有风格）：短、冷、帝王腔，把"帝国"说成进行时而非过去时。

英文语气：declarative, clipped, ledger-like. 不用感叹号，不用俚语，
允许极少量古语助词（"would", "shall"）制造威仪，但避免莎士比亚腔。
