**用途**：Mod 首页 / 创意工坊封面 / 角色宣传图。
**构图要点**：主体偏右占 1/2～2/3；缩略图下冠、剑、肩部剪影可辨；背景同色系；
以残月、三片燃烧羽毛（一焦）、远处残破王座暗示过去；不堆砌家族成员。
（v01 构图与风格获用户认可，v03 起仅随锚点更新配色。）

**当前提示词（v03，prompts.txt 第 1 条）：**

```
男性东方帝王，外貌约三十五岁，长方面庞，颧骨清晰，剑眉凤目，冷青色眼睛，额头与面部干净，无任何痣、面纹或额饰。深青近黑长发高束于暗金色断口新月形王冠之下，余发垂落肩后。身形高挺修长，肩背笔直。身穿青鸾蓝色立领劲装，衣色由肩背的青鸾蓝向下摆渐变月白色，仅以极少量星金纹路点缀；左肩为冷银白色凤首肩甲、暗金包边，与衣色明确区分，右肩覆蓝青渐变月白的青鸾羽衣，左甲右羽的不对称结构。腰束玄色玉带，悬一枚凤首衔月纹方形印玺。右手持青鸾钩剑，长剑尖端带反向弯钩。背后悬浮一轮残缺的银白月轮。整体以青鸾蓝为主色调，只点缀少量暗金。在此角色基础上创作一张粗粝手绘风格的阴郁奇幻角色海报：夸张剪影、高对比色块、版画式笔触。画面比例16:9（建议1920×1080）。人物位于画面右侧，占画面约二分之一到三分之二，侧身回望，右手钩剑垂于身侧，左手掌心向上腾起青蓝色炽焰，焰芯一点金。左侧背景使用同一青蓝色系：深青夜空中一轮巨大的残月，三片燃烧的羽毛自月中飘落，其中一片焦黑，远处地平线上有一座残破王座的剪影。背景元素与人物保持同一青蓝色系，不出现其他人物，不出现任何文字。缩略图尺寸下王冠、钩剑与左甲右羽的剪影必须清晰可辨。
```
