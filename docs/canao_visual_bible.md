# 残傲视觉设计圣经

> 一切残傲相关生图、卡图、图标的最高依据。叙事依据见 `canao_character_bible.md`。
> 色彩 HEX 为参考值，允许 ±10% 浮动，**不要求机械匹配**，但色相关系不得颠倒
> （青鸾永远是冷色，天凤之火永远以青蓝为主、金为芯）。

## 一、角色视觉核心（3.1）

| 维度 | 设定 |
|---|---|
| 外观年龄 | 人类约 35～40 岁。成熟君主，不是少年，也不是老者 |
| 身高感 | 高。在构图中应显得比周围人物高半头以上；直立时头顶接近画面上缘 |
| 身体比例 | 修长，约 7.5～8 头身；四肢长，肩不夸张宽，无肌肉虬结 |
| 体型 | 清瘦而挺拔。"剑入鞘"的体态——静止时收敛，发力时锋利 |
| 脸型 | 长方面，颧骨清晰，下颌线干净利落，不圆不尖 |
| 眉眼 | 剑眉，斜飞入鬓；凤目，眼尾微挑；目光是"俯视的平静"，不瞪不眯 |
| 鼻梁/下颌 | 鼻梁高直；下颌收得紧，侧面轮廓呈"刀背"线 |
| 肤色 | 冷白，带极淡的青灰调（久居梦留山，不见暖日） |
| 发色 | 深青近黑，在光下泛青蓝光泽（不是纯黑，不是亮蓝） |
| 发型 | 长发束于冠下，高束髻，余发垂落肩后；额前无碎发——帝王不露乱发 |
| 瞳色 | 冷青，瞳仁深处一点金（近景可见，远景只读冷青） |
| 常态表情 | 无表情。唇线平直，眉不皱不扬——"俯视的平静" |
| 表情变化 | 极窄：微阖目（痛）、眉峰微动（怒到极点反而最静）、嘴角一线（仅云霜在场时） |
| 头饰 | **青鸾残月冠**：暗金色断口新月形冠，缺口朝左上方；冠体是几何的（帝王），断口是有机的（失去） |
| 内层服装 | **青鸾蓝立领劲装**，窄袖收口；衣色由肩背的青鸾蓝向下摆渐变月白色，仅以极少量星金纹路点缀；布料哑光 |
| 外层服装 | **不对称结构**：左肩几何凤首肩甲（**冷银白为主、暗金包边**，与青鸾蓝衣色明确区分；金属、稳定、方块感），右肩青鸾羽衣（蓝青渐变月白；羽毛、流动、曲线感）——一帝一鸾，一静一动 |
| 护甲结构 | 仅左肩+左臂甲，胸腹无重甲（他不是坦克，是君主）；甲片为冷银白方形叠甲、暗金包边——甲色与衣色不得混同 |
| 肩部轮廓 | 左肩方正出角，右肩羽披下垂成弧——剪影上"一方一弧"，缩略图即可辨认 |
| 腰部结构 | 玄色玉带，正中悬**方形帝国印玺**（凤首衔月纹），右侧挂一卷短诏 |
| 鞋靴 | 玄色高筒战靴，暗金线滚边，无跟无翘头 |
| 披风/羽衣 | 右肩羽衣延伸为半幅羽披，长及膝弯；羽色由肩部的蓝青渐变为梢头的月白 |
| 主武器 | **青鸾钩剑**：一柄长剑，剑尖带一道反向弯钩（"勾法"的具现）；剑身窄长，冷青钢色，近柄处铸星纹 |
| 副武器/法术媒介 | **残月轮**：背后悬浮的银白残缺月轮，环周缀星芒——星月合击的媒介，也是云霜的意象 |
| 青鸾元素 | 右肩羽衣、钩剑、冷色内卷羽形；青鸾是"人形时的他" |
| 天凤元素 | 火焰形态（青蓝炽焰）、法相（巨大凤翼光影）；天凤是"燃烧时的他" |
| 星月元素 | 残月冠、残月轮、剑身星纹、羽梢月白渐变 |
| 帝国纹章 | **凤首衔月方印**：几何方形玺面，内刻凤首衔一弯新月；用于腰间印玺、旗帜、卡图角落 |
| 火焰形态 | 青蓝色炽焰，外焰冷蓝、内焰月白、焰芯一点金；火形向上收拢如花瓣，不炸散 |
| 羽毛形态 | 青鸾羽：长、窄、向内弯卷，冷色；天凤羽：宽、向外张开，暗金镶边。二者永不混用 |

## 二、视觉主题（3.2）

### 2.1 五大母题

1. **青鸾天凤的蓝色炽焰**：冷色的火。烧得越烈越安静。所有火焰场景的第一主题。
2. **帝王的稳定几何 × 羽毛的不稳定曲线**：方与弧、直与卷的对抗统一，落实在左甲右羽、
   方印与残月、直线站姿与羽披流动上。构图上：人物用几何，环境用曲线。
3. **火焰与月光**：他自己的光是火（青蓝），云霜留给他的光是月（银白）。
   画面中两者相遇之处即视觉焦点。
4. **王冠与枷锁**：冠是断的，印是方的，诏令是卷的——王权的每件器物都同时是束缚。
   表现"在位"的场景永远带一处"断裂/锁链/缺口"细节。
5. **姐姐留下的遗憾**：残月、缺口的圆、空着的右手位（他右侧永远留出一点空，
   那是云霜该站的位置）。【新增：右侧留白】

### 2.2 形态使用规则

| 形态 | 使用场合 | 规则 |
|---|---|---|
| 人类样态 | 默认。对话、选择界面、绝大多数技能/攻击卡、海报 | 人形+全部锚点特征 |
| 人类样态＋凤凰法相 | 能力牌、终结技、天凤形态、涅槃/浴火高潮帧 | 人形保持完整清晰，背后或上空浮现巨大凤翼/凤首光影（半透明、青蓝火焰构成）；**法相不遮挡人物面部与钩剑** |
| 凤凰样态（全鸟） | **仅**浴火重生、死亡-复生叙事帧、先古牌 | 全鸟青鸾形，不出现人体；一局中一次都嫌多的稀缺画面，用完即回人形 |

### 2.3 意象-人物对应表

| 意象 | 归属人物 | 用法 |
|---|---|---|
| 残月/缺月/月轮 | **云霜** | 银白、静止、永远在画面偏上方；残缺的圆只属于她 |
| 星/星芒/星轨 | **残傲自身**（青鸾勾法探星） | 尖锐四芒或八芒，冷青或星金 |
| 星月同辉 | **魂合**（502 后的他们） | 星与残月同框且相互映光，仅用于最重的叙事帧 |
| 断冠/锁链/朱批 | **世昌**与王位之重 | 暗金断裂件；与王权场景伴生 |
| 流萤/散而不灭的光点 | **倩雪**（流萤剑法） | 暖赤金色小光点群，散飞如萤；倩雪为赤凤，专用赤金 |
| 鸑鷟紫羽/紫黑火 | **辉雪** | 紫黑羽、紫焰；鸑鷟八天凰凤的专属色，只在她身上用 |
| 一盏不灭的灯 | **寒羽** | 梦留山的孤灯，暖黄一点，永远很小、很远；她一岁上山，灯是她的童年 |
| 星尘/坠星 | **尘星** | 燃尽的细小星屑，散于战场夜空 |
| 三片羽毛 | **三个女儿** | 两片完好（辉雪紫、辉月白）一片焦黑（辉雨） |

| 腐绿瘀紫的侵蚀纹 | **瓦魔族/魔族** | 对比色系，见色彩系统 |

**禁止大面积使用的颜色**：高饱和纯红（`#FF0000` 系）、亮紫、翠绿、纯白（作背景）、
粉色系。大面积暖色只允许出现在"梦留山灯火/流萤"类叙事帧，且必须被青蓝环境包围。

**配色总则**：任何残傲主视觉画面，青鸾蓝+月白+银白占 70% 以上；衣身的金色只能是
"一点点"——星金点缀不超过 5%，暗金（冠、甲包边、印玺）合计不超过 10%；
魔族对比色只出现在敌人一侧。

### 4.2 不可改变 × 可以简化

| 任何情况下不可改变 | 可按用途简化/省略 |
|---|---|
| 男性；面部：长方面+剑眉凤目（不得变成圆脸/少年脸/老者） | 残月轮（局内小图可省略或缩小） |
| 断口新月冠（暗金） | 印玺纹样细节（小图只保留方形轮廓） |
| 左甲右羽的不对称结构；甲为冷银白、衣为青鸾蓝，二者不得混色 | 诏令卷轴、玉带细节 |
| 衣身青鸾蓝向月白渐变，金色只能是零星点缀 | 羽衣的羽毛根数与纹理 |
| 青鸾钩剑（尖端逆钩） | 瞳中金点（远景/小图省略） |
| 束发（不得披头散发） | 表情（可按叙事在§一"表情变化"范围内调整） |
| 青蓝主色+暗金点缀（不得颠倒冷暖、不得金多于蓝） | 靴、袖口等次级服装细节 |

### 4.3 禁止出现

- 现代服装、科幻机械结构、日式校园元素、过度裸露；
- 与杀戮尖塔原生角色重复的剪影级特征：铁甲战士的角盔与红金重甲、静默猎手的
  绿兜帽蒙面、故障机器人的独眼球形核心、任何原生角色的标志性配色组合；
- 双钩、双剑、巨剑（武器形态已固定为单柄钩剑）；
- 暖红主色的火焰（那是赤凤/倩雪的，不是残傲的）；
- 完整的圆月（月亮必须是残月——完整圆月属于"没有失去过"的世界）；
- 面部任何痣、额饰、面纹（脸部识别只依靠冠、眉、目与轮廓）。

### 5.2 构图规则

- 主体占画面 **55%～85%**，允许越界裁切；**一次只保留一个核心动作**。
- 近景与夸张透视为默认：手、武器、印玺、火焰推到画面前方。
  **禁止平视远景全身站姿**——叙事帧（F 家族）改用"前景巨大剪影+远景极小"的夸张透视。
- **人物默认只出局部**（2026-07-30 用户重申，第 13 批教训）：对照 45 张原生样本，
  九成卡图是"手/拳/脸/器物怼镜头"。残傲默认只出手臂、肩甲、胸像以上的局部，
  **全身出镜必须给出叙事理由**（目前仅 F 家族叙事帧与海报/概念图允许）；
  攻击卡优先"臂+剑+命中瞬间"，面部可完全不出镜；
  人物与怪物同框时**两者都必须被镜头裁切**，禁止"两人全身对峙"式构图。
  特写化的挥砍动作比全身挥砍更稳——全身挥剑姿势曾被用户判为"不自然"（星月终式/燃羽突袭 v01）。
- 背景只做渐变、云状块面、剪影或少量环境提示，细节密度明显低于主体。
- **背景色彩多元（参照 45 张原生样本）**：背景为高饱和单色/双色渐变或简化场景块面，
  按卡牌情绪选色（深青、靛蓝、墨绿、暗紫、暖深棕、晨昏青灰赭均可）；
  **禁止默认纯黑/近黑底**——近黑只允许 E 家族祭仪/夜晚题材，且用深蓝黑或墨紫而非纯黑。
- **每张卡独立成篇**：家族只是松散指引，每张卡的配色、视角、内容都可以独立创新，
  不必与家族先例一致；先问"玩家打出这张牌时发生了什么"，再自由选色与构图。
- **构图去重（2026-07-30 用户指出，第 15/16 批教训）**：卡池级检查——禁止连续多张
  使用"一把剑从左向右劈向右侧怪物"或"一把剑从左下至右上斜贯整个画面"的同款构图；
  同一张卡的攻击动作必须从剑击、火焰、星月、军阵、威压、器物、手势等不同解法中
  重新选择，不允许换皮复用。特效（闪光、冲击星芒、能量弧、碎片、光晕）按几何图形处理。
- 先锁剪影与配色，再加能量特效。

### 5.3 配色原则（每张卡独立选色，家族不锁定）

- 唯一硬性要求：**残傲本体出镜时**，衣甲配色服从 §4 锚点（青鸾蓝衣 + 冷银白甲）。
- 其余一切——背景、特效、敌人、环境色——按该卡内容情绪**独立选择**，
  参照 45 张原生样本的多元高饱和路线；同一视觉家族内部也鼓励色相差异。
- **配色去重（2026-07-30 用户指出，第 15/16 批"黑+蓝扎堆"教训）**：每批完稿后
  必须做拼版色域检查，禁止一批内大半画面同为"深青底+青蓝光"。已通过的多色先例
  可作为锚点：浴火军旗（暖红底）、传令（灰+金）、暂避锋芒（青灰）、燃羽突袭 v02
  （暖深棕）、王权（暖棕+暗金殿内）、桂轮 B（墨绿）、星辉护阵 B（玄青+星金）。
  候选扩展色域：暖红棕、暖深棕、晨昏青灰赭、暮紫、墨绿、玄青+星金、灰+金。
- 鼓励视角与内容创新：同一机制不强制复用先例构图；
  先想"玩家打出这张牌时发生了什么"，再自由构图。
- 保留的松散题材倾向（仅为避免撞车，不构成配色义务）：
  A 偏火焰主体、B 偏天体、C 偏器物仪式、D 偏战场动势、E 偏"失去"瞬间、F 偏叙事远景。
- E 家族仍允许"粗粝绘画变体"（烟雾水彩晕染、纸张颗粒、不均匀墨线），
  但**必须保留强剪影与单一焦点**，不得退化为普通概念图。

### 5.4 负面提示词（卡图通用）

中文：照片写实，电影级写实，3D渲染，光滑塑料材质，日系动漫脸，精细线稿，纤细轮廓，柔和空气喷枪渐变，复杂写实背景，远景全身站姿，静态对称构图，低对比，灰泥色，过度细节，杂乱焦点，卡牌边框，标题，数字，文字，图标UI，水印，Logo
English: photorealistic, cinematic realism, 3D render, glossy plastic, anime face, delicate clean line art, thin outlines, soft airbrush gradients, realistic detailed environment, distant full-body pose, static symmetrical composition, low contrast, muddy colors, excessive micro-detail, multiple competing focal points, card border, title, numbers, text, UI icons, watermark, logo

### 5.5 与角色锚点的配合

残傲出镜的卡图 = **§4.1 锚点全文 + 内容描述 + §5.1 风格骨架 + §5.4 负面词**。
锚点保证"是同一个人"，骨架保证"是同一种画"。风格冲突时以画风统一为先，
锚点中的材质细节允许被赛璐璐化简化（如渐变衣色可读作两至三个硬边色面）。

### 5.6 尺寸与画幅

- 画幅优先 **4:3 横向**（工具默认输出可能自作主张变竖幅——
  **每条卡图提示词必须在最前面显式写"画面比例4:3横图（宽大于高）"**，第 6 批教训）。
- 裁切到 25:19 时焦点位于中央安全区。
- 先古牌等竖幅另行确认焦点。普通卡图比例规范不变（母版 2000×1520，见流程文档）。

## 六、与杀戮尖塔原生元素的连接（3.5）

### 6.1 原生卡图的联动实例（有据可查）

- **StS2 第一幕蘑菇怪（雾菇）出现在全部五名原生角色的卡图中**——每个角色至少一张卡
  画的是"我在打这只怪"，无色牌"群起攻之"更是一群怪围殴它。这是"把原生怪物画进
  自定义卡图"最直接的原生先例。
- **"羞耻"卡图**：画面中心是故障机器人，边框三只手分别取自 StS1 三位主角——
  跨角色客串只用**肢体与道具**，从不画完整的第二个角色。
- **Regent 的星座背景板**：悬浮可见 StS1 内容的星座（蛇、球形守卫、咔咔教徒、纸蛙
  遗物、三柱、机甲小队）——**背景是官方认可的彩蛋区**。
- **StS1 黄金范式**：仪式匕首（卡）↔ 巢穴事件 ↔ 觉醒者（Boss 胸口插着同一把刀）——
  一个意象同时出现在事件、卡图、Boss 三处。遗物（永恒羽毛、鸟面瓮）反复锚定同一 Boss。
- **Apparition / Bite**：事件专属 NPC 直接成为卡图主角，卡只能从该事件获得。
- **官方致敬方法**：借构图、重绘于世界内（铁甲战士终版姿势借自《苍翼默示录》白面；
  StS2 卡图致敬火箭飞拳、克劳德、强欲之壶、月之暗面棱镜等）——借用姿势与构图是
  官方自己的做法，**主体必须重绘为尖塔视觉语言**。

### 6.2 官方美术原则（MegaCrit 自述）

1. **小尺寸可读性是第一约束**： Casey 因"小人形在屏幕上读不清"而转向非人形设计；
   StS2 聘艺术总监的标准就是"画小东西清晰简洁"。
2. **StS2 五支柱**：Playful（题材黑暗但语言 playful）、Crisp（少油画感）、Liveliness、
   Cinematic、**Colorfuler（更鲜艳=提高界面可读性）**。
3. **融入世界靠"母题库"，不靠抄设计**（艺术总监 Marlowe Dobbe）：解剖 StS1 的气质由
   哪些母题、重复视觉、种族、建筑构成。例子：StS1 里**极少露全脸**——"脸露太多
   就不像尖塔的人"；敌人设计门槛是"**够不够怪**"。
4. **卡图流程**（StS1/2 卡图画师 Anailis Dorta）：每卡 2～3 张草图，从卡名与描述出发，
   限时调研姿势与历史器物参考；跨画师的一致性来自"接近的情绪与形状"。
5. **对比度为玩法服务**（背景画师 Bruce Brenneise）：构图必须考虑角色在画面空间中
   的移动与可读性。

### 6.3 对残傲卡图的可行建议（按优先级）

1. **让原生怪物当"对手/观众"**：挑 2～3 张 D 家族攻击卡，画面彼侧画可辨认的
   StS2 原生怪物（第一幕雾菇、虫群、gremlin 佣兵）作为被打对象——怪物是锚点，
   残傲的剪影永远不直接与原生英雄竞争。
2. **以母题而非剪影致敬原生英雄**：如需呼应 Regent 的星辰锻造，就在 F 家族星图中
   藏一组"锻星"星轨；呼应铁甲战士只用一片红金碎甲（禁角盔）。第二个原生角色
   在残傲卡图中**永远只以道具/局部出现**。
3. **背景彩蛋区**：在 B/F 家族卡图背景放入尖塔场景元素——第一幕海港、营火提灯、
   三柱轮廓、休眠尖塔剪影、或一组凤凰形星座。彩蛋只占背景层，不抢焦点。
4. **卡-事件-遗物三点锚定**：给一件核心意象（候选：**断口新月冠**或**帝国年表**）
   安排"遗物图—卡图—先古对话"三处复用，对标仪式匕首范式。
5. **脸规则**：StS 世界少露全脸。残傲的折中方案（已纳入锚点）：近景肖像允许清晰
   面部（断口新月冠+剑眉凤目是识别特征），但**局内图与远景卡图用冠影/火光遮住半张脸**，
   保住"尖塔感"。
6. **自家卡池内的母题复用**：残月、方印、内卷火舌三个母题在全部卡图中反复出现，
   用最便宜的方式制造"同一世界"感。
7. **借构图不抄设计**：可参考古典帝王画像、神话凤凰的姿势与构图，但主体必须是
   尖塔视觉语言下的重绘；不复制任何原生角色的"站姿+道具"组合。

### 6.4 img2img 原生联动工作流（参考图驱动，2026-07-30 起）

> 此前所有卡图均为纯文生图；2026-07-29 起 aizex 新增 `edit_image`（文+图生图），

- **通道**：aizex `edit_image`（MCP；Kimi 侧经 `aizex-image-bot/mcp_batch.js` 批处理，
  用法见根目录 `mcp.md`）。文生图不变，仍走 generate.js / generate_image。
- **参考图库**：
  - `../sts2_enemy_collection/images/`——StS2 官方怪物立绘 81 张（用户已剔除占位/半成品），
    索引 `manifest.csv`（名字/类别/幕/HP/来源 URL）；
  - `../sts2_character_collection/images/`——五名原生角色选人立绘
    （Ironclad/Silent/Regent/Necrobinder/Defect，PNG 为 avif 转换版，注意左侧带游戏 UI 文字，
    作参考时只取右半人物）。
- **联动提示词结构**（在文生图五段式最前面加"特征锁定句"）：
  `画面比例4:3横图` → **参考图特征锁定**："上传的参考图是〈怪物一句话描述〉，
  严格保留其〈2~3 个识别特征〉，重绘进下面场景作为〈角色定位〉" →
  §4.1 锚点（残傲出镜时）→ 内容 → §5.1 风格骨架 → §5.4 负面词。

  （避免人脸被参考图带偏，泪痣事件教训）。
