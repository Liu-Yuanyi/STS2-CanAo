# VFX 特效触发指南（测试用，2026-08-16）

> 15 张 VFX 单帧（各 A/B 两版）实装后，按本表做对应动作即可在游戏内看到效果。
> 挂载方式：攻击类走 `AttackCommand.WithHitFx`（命中特效）/ `WithAttackerFx`
> （出手特效）；主题与反馈类挂到对应卡牌 `OnEnqueuePlayVfx` 或 Power/事件触发点。
> 全部为单帧 PNG + 缩放/旋转/透明度动画组合。

## 攻击类（打牌即触发）

| VFX | 触发动作 |
|---|---|
| 普通斩击 | 打出任意单体攻击牌（打击、青鸾勾法、决断…）命中敌人时 |
| 重击冲击 | 打出大伤害攻击牌（灭世、凤瓦决战、孤剑打击）命中时 |
| 范围爆发 | 打出 AoE 攻击牌（灰烬风暴、王威压境、尘土之战、羽列千军浴火触发）命中全体时 |

## 残傲主题类

| VFX | 触发动作 |
|---|---|
| 青鸾冷焰 | 任意**浴火**触发时（例：打出祭火消耗手牌中的浴火牌；或打浴火斩/火刃被消耗） |
| 天凤烈焰 | 打出能力牌**天凤形态** / **凤焰不息** 时 |
| 星芒爆发 | 获得**星**时（例：观星问月选"观星"、青鸾勾法、星辉护阵） |
| 月轮斩痕 | 打出月系攻击牌：**月斩**、**碎月一击** |
| 星月合击 | **星月合击**打出命中时（先凑 1 星 + 1 月自动产合击） |
| 帝王诏令印记 | 打出**诏令**时（传令/密诏/帝国税契开局入手后打出） |

## 状态反馈类

| VFX | 触发动作 |
|---|---|
| 获得 Buff | 获得凤威/力量等正面状态时（例：打出示威、凤威酒） |
| 获得 Debuff | 被敌人上虚弱/易伤时；或打出取势败中/折冠自减凤威时 |
| 消耗资源 | 手牌被**消耗**时（例：打出祭火、帝诀/焚诀选牌消耗） |
| 获得资源 | 获得**月**/能量时（例：打出桂轮、问月、星月轮转回费） |
| 姿态切换 | 残傲无原生姿态——本特效挂**复辟**（凤威归零重置）打出时 |
| 召唤/消散 | 衍生牌入手时（例：打出援军产火刃、凤火军械回合开始产火刃） |

## 快速全览路线（一局内）

1. 开局：税契给诏令 → 打出诏令（诏令印记）；
2. 打桂轮（获得资源/月）→ 观星问月选星（星芒爆发）→ 自动产星月合击 →
   打出（星月合击特效）；
3. 打月斩（月轮斩痕）、打灭世（重击冲击）、灰烬风暴（范围爆发）；
4. 打祭火消耗浴火牌（消耗资源 + 青鸾冷焰）；
5. 打示威（获得 Buff）；打复辟（姿态切换）；打援军（召唤/消散）。

## 退路说明（已确认可行）

- 当前 mod 攻击牌**没有任何命中特效**（从未调用 WithHitFx）。
- 若自制 VFX 做炸：给攻击牌统一加一行
  `.WithHitFx("vfx/vfx_attack_slash")`（重击用 `vfx_heavy_blunt`、
  AoE 用 `vfx_attack_blunt`）即可全套退回原生视觉，零素材、零风险；
  也支持**按卡部分退回**（哪张不满意退哪张）。
