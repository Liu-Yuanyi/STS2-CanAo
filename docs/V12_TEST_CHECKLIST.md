# v12 实机测试细则（2026-08-15 部署）

> 按风险从高到低排列。每项标注改动来源（v12修改.md 条目号）。

## 一、最高优先：重做与新机制

1. **万邦来朝（#27）**：打出获得 1（2）凤威；此后**每回合开始**手牌加入 1 张
   **其他角色**的随机能力牌，且带**虚无**（回合结束消失）。验证点：
   - 单人游戏：加的牌来自五名原生角色的能力牌池，不含残傲自己的牌；
   - 重复打出两张万邦来朝 → 每回合加 2 张（Counter 叠层）；
   - 加入的牌带虚无、当回合可正常打出；
   - 手牌满（10 张）时不应报错（加不进去属正常）。
2. **不堕（#25）**：负凤威时，每回合**前 1（2）次**打出的星月合击伤害/格挡
   不被拉低（按 0 修正）；第 2（3）次起正常吃负修正。验证点：
   - 负凤威 -3 时第一张合击数值 = 基础值，第二张 = 基础值-3；
   - 重复打出不堕 → 前 n 次免疫；**升级不再获得固有**（固有已删）。
3. **观星问月（#15）**：选择界面两个选项——未升级给 2、升级给 3；
   选项牌面文本应显示正确数值（选项与主卡升级同步）；
   旧的"没生成合击则抽牌"效果已删除。
4. **帝国税契（#37）**：战斗开始 +1 诏令入手（不变）；**不再扣金币**；
   **战斗结束时**获得金币 = 本场战斗打出过的诏令总数。验证点：
   - 跨回合累计（第 1、3 回合各打 1 张 → 结束 +2 金币）；
   - 一张没打 → +0 金币不弹提示；
   - 浴火自动打出诏令、密诏入弃牌堆等路径是否正确计入/不计入。
5. **星月轮转（#31 新卡）**：每回合**第 2 张**星月合击生成时 +1 能量，
   每回合只触发一次；第 1、3 张不触发；升级后 0 费；
   重复打出 → 触发时 +n 能量。
6. **按剑（#30 新卡）**：1 费 8（11）格挡；选 1 张手牌放回**抽牌堆顶**
   （下回合抽到）；空手可打出（只拿格挡）；升级只加格挡。
7. **宴请八方（#24）**：已改为**稀有能力牌 2 费**（多人专属）：
   所有玩家恢复 3（5）生命并各抽 1 张；单人模式不出现在卡池/奖励。
8. **聚精会神（#18）**：保留（握在手中不消失）；获得 2（3）费；打出后消耗。
9. **长鸣（#19）**：先获得 6（7）格挡，再从消耗牌堆选 **1** 张移至抽牌堆；
   升级后格挡 7 且**不消耗**。
10. **帝国威严（#26 改名+调整）**：每回合**第一次**打出诏令 +1 凤威，
    第二次不再给；卡面名称显示"帝国威严"；升级固有保留。
